## 1. Executive Summary & Root Cause Analysis

### The Root Cause of the 53.6% Zero-Shot Ceiling
In Night Shift v3, domain classification relied on a hybrid lexical pipeline:
- Keyword term frequency (`matchTerms` array hits in `fingerprints.json`)
- Heuristic regex patterns ($f_1 \dots f_8$)
- L2-regularized logistic regression over lexical features (`ecs_weights.json`)

While this yielded **88.9% in-sample accuracy** when keywords were tuned against error prompts, it suffered a sharp drop to **53.6% zero-shot accuracy** on un-mined novel prompts (`routingEvalBlindV2.test.js`). 

**Why Lexical Routing Fails Zero-Shot:**
Lexical matchers cannot capture semantic intent without exact word overlap. For instance:
- *"did NASA really lose the original Apollo 11 moon landing telemetry tapes?"* fails to match `fact-check` because `"Apollo 11"` and `"telemetry tapes"` are absent from the dictionary.
- *"refactor monolithic controller into domain services"* routes to `creative` instead of `coding` because `"monolithic"` and `"controller"` hit storytelling registers.

### The v4.0 Solution: Local ONNX Semantic Embeddings
REI.ai v4.0 replaces token-level regex matching with **dense vector cosine similarity** using a quantized, local-first ONNX embedding model (`all-MiniLM-L6-v2` via `@xenova/transformers` / ONNX runtime):

```
User Query 
   │
   ▼
[ Local WASM / ONNX Model: all-MiniLM-L6-v2 (<20ms) ]
   │
   ▼
Dense 384-dimensional Vector u
   │
   ▼
[ Cosine Similarity vs 15 Pre-Computed Domain Centroids c_i ]
   │
   ▼
Top Domain Match + Normalized DAS Entropy [0.0, 1.0]
   │
   ▼
[ CARDO Guard Cost Gate (CheapRouteConfidence = 1.0 - HS) ]
```

## 2. Architectural Design: Core Components

### Component A: Local Semantic Embedder (`src/lib/semanticEmbedder.js`)
- Uses `@xenova/transformers` in Node/browser environments with ONNX runtime.
- Loads quantized `all-MiniLM-L6-v2` (23MB static WASM/ONNX weight artifact cached locally).
- Converts text input to a normalized $\mathbb{R}^{384}$ dense vector $\vec{u}$ in $<20\text{ms}$.

### Component B: Pre-Computed Domain Centroid Matrix (`data/ml/domain_centroids.json`)
- Pre-computes 384-dimensional centroid vectors $\vec{c}_1 \dots \vec{c}_{15}$ for all 15 domain fingerprints.
- Centroids are generated by embedding 200+ canonical exemplar prompts per domain and calculating the mean unit vector:
  $$\vec{c}_i = \frac{\sum_{j=1}^{K} \text{embed}(P_{i,j})}{\|\sum_{j=1}^{K} \text{embed}(P_{i,j})\|}$$

### Component C: Cosine Similarity & Vector DAS Engine (`src/lib/semanticHingeClassifier.js`)
- Computes Cosine Similarity $\text{Sim}(\vec{u}, \vec{c}_i)$ for all 15 domain centroids:
  $$\text{Sim}(\vec{u}, \vec{c}_i) = \vec{u} \cdot \vec{c}_i \in [-1.0, 1.0]$$
- Applies Softmax activation over similarity scores to derive probability distribution $P = [p_1 \dots p_{15}]$:
  $$p_i = \frac{e^{\text{Sim}(\vec{u}, \vec{c}_i) / \tau}}{\sum_{k=1}^{15} e^{\text{Sim}(\vec{u}, \vec{c}_k) / \tau}}$$
- Calculates normalized Shannon Entropy for Domain Ambiguity Score ($\text{DAS}$):
  $$\text{DAS} = \frac{-\sum_{i=1}^{15} p_i \log_2(p_i)}{\log_2(15)} \in [0.0, 1.0]$$

## 3. Implementation Roadmap (5 Phases)

### Phase 1: Dependency & Local Model Harness Setup
- Add `@xenova/transformers` dependency.
- Create `src/lib/semanticEmbedder.js` with WASM/ONNX lazy initialization and fallback.
- Write unit tests (`src/lib/semanticEmbedder.test.js`) asserting vector dimension (384) and latency (<25ms).

### Phase 2: Offline Centroid Matrix Generation Script (`scripts/generate-domain-centroids.mjs`)
- Create Node.js script embedding 200+ exemplar prompts per domain across all 15 fingerprint categories.
- Export pre-computed static JSON artifact: `data/ml/domain_centroids.json` (~45KB).

### Phase 3: Semantic Classifier Engine Integration (`src/lib/semanticHingeClassifier.js` & `nightShiftRouter.js`)
- Wire `computeSemanticHingeScore()` into Layer 1.5 of `nightShiftRouter.js`.
- Blend semantic similarity score with `cheapRouteConfidence = 1.0 - HS`.
- Protect with Solvency fallback (`try/catch` fallback to lexical catalog on cold-start or error).

### Phase 4: Zero-Shot Un-Contaminated Evaluation Suite (`src/__eval__/routingEvalBlindV2.test.js`)
- Evaluate v4 semantic router against the 28-prompt un-contaminated **Blind Set V2** (`routingEvalBlindV2.test.js`).
- Assert pre-registered pass condition: **Zero-shot out-of-sample accuracy $\ge 85.0\%$** and **Cost Savings $\ge 78.0\%$**.

### Phase 5: UI & Telemetry Readout Upgrade (`ToolsLanding.jsx` & `REI.jsx`)
- Update live router demo readout to display `Semantic Vector Match` ($S_{\text{cos}}$) and `DAS` entropy micro-bars.
- Update `data/telemetry.json` and `CHANGELOG.md`.
