### 🚀 Flagship Project: [REI.ai](https://github.com/aaronmarchant96-max/rei-ai)

> **"You pay REI because REI makes the total number smaller."**

[REI.ai](https://github.com/aaronmarchant96-max/rei-ai) sits directly in front of AI agents (Cursor, Cline, Aider) and backend pipelines to automatically route routine requests to sub-cent fast models while reserving expensive frontier models (GPT-4o) for complex architectural reasoning.

- ⚡ **Pre-Spend Selection**: Executes deterministic model routing in **< 10ms** before token spend.
- 💰 **94–96% Paid Routing Savings**: Verified cost reduction across multi-model workloads.
- 🛡️ **Delivery-Gated-v1 Receipts**: Truncated/incomplete turns yield **$0.00 eligible savings**—you only pay for quality-passed responses.
- 🔑 **Bring Your Own Key (BYOK)**: Customer-owned provider keys; zero inference balance-sheet liability.
- 🧪 **100% Green Test Battery**: Backed by **1,195 automated tests across 105 test suites**.
